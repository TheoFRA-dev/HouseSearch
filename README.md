# HouseSearch

Prototype de site web de recherche de maisons à partir de plusieurs plateformes de vente immobilière.

## Lancer localement

```bash
python -m http.server 3000
```

Puis ouvrez http://localhost:3000.

## Déploiement Railway

Le fichier Procfile permet un déploiement simple sur Railway avec :

```bash
python -m http.server 8080
```
